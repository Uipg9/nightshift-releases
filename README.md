# Nightshift releases

Downloads and update files for Nightshift. The apps check `latest.json` here for new versions.

- Windows: [Nightshift-Windows.zip](https://github.com/Uipg9/nightshift-releases/raw/main/downloads/Nightshift-Windows.zip) (unzip, run `Nightshift.exe`)
- What's new: [NOTES.md](NOTES.md)
- Updates install from inside the app: Settings > Updates, or the tray icon's "Check for updates".
